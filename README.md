# Aura-Square
Landing page conceitual de um smartwatch standalone com Android nativo, desenvolvida como projeto de estudo prático para consolidar o módulo de HTML5 e CSS3 do curso de Programador Web no IFF.

Veja o projeto rodando ao vivo: [https://thiagord10-create.github.io/Aura-Square/]

Tecnologias e Conceitos Aplicados
Este projeto foi construído do zero, priorizando boas práticas de mercado, acessibilidade e design responsivo:

HTML5 Semântico: Uso rigoroso de tags estruturais (<header>, <nav>, <main>, <section>, <footer>) e elementos semânticos como <figure>, <figcaption> e listas de definição (<dl>).

Organização de Dados: Construção de tabelas complexas utilizando o atributo rowspan para mesclagem de células verticais e estruturação limpa de especificações de hardware.

Formulários Avançados: Fluxo completo de captação de leads e suporte com <fieldset>, <legend>, campos de rádio (radio), inputs rotulados (label for) e o elemento inteligente <datalist>.

CSS3 Moderno:

Dark Mode Imersivo: Paleta de cores baseada em tons profundos (#0a0a0a e #151516) com destaques em azul tecnológico (#2997ff).

Efeito Parallax: Implementado via background-attachment: fixed para gerar profundidade visual.

Animações Personalizadas: Regras de @keyframes para criar o efeito de flutuação contínua com sombras dinâmicas (filter: drop-shadow).

Multimídia Nativa: Integração de vídeo em loop contínuo e elementos responsivos diretamente na página.

Sobre o Projeto
O AuraSquare Pro é um produto fictício criado com o objetivo de testar e demonstrar habilidades avançadas de front-end. Cada linha de código foi pensada para garantir uma navegação fluida, acessível e visualmente impressionante, simulando o padrão de grandes portais de tecnologia.
